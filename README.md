# Office Inline Preview

在 Obsidian 笔记正文中预览 Word、Excel 和 PowerPoint 文件，让参考资料与笔记放在一起。

插件支持本地 `.docx`、`.xlsx`、`.pptx` 文件，在阅读模式和实时预览模式中显示内容。文档在本机解析，无需安装 Microsoft Office 或 LibreOffice，也无需上传文件。

当前版本：**0.2.0**。适用于 **Obsidian 桌面端 1.5.0 及以上版本**。

## 功能

| 功能 | 说明 |
| --- | --- |
| Word 预览 | 显示正文、表格和内嵌图片，按预览框宽度等比例缩小页面 |
| Excel 预览 | 显示单元格内容和基础格式，支持切换可见工作表 |
| PowerPoint 预览 | 显示静态幻灯片，支持翻页和输入页码跳转 |
| 正文嵌入 | 使用 `![[文件路径]]` 或 `office-preview` 代码块 |
| 调整尺寸 | 默认宽度 100%、预览区域高度 360px，右下角可拖动调整 |
| 独立保存尺寸 | 每个预览的尺寸写入当前笔记，同一文件可设置多个不同大小的预览 |
| 查看源码 | 定位当前预览对应的 Markdown 嵌入链接或代码块 |
| 刷新预览 | 支持手动刷新，附件保存变化后也会自动刷新 |
| 预览信息 | Excel 和 PowerPoint 的说明通过信息按钮弹窗查看 |

预览不会改写 Office 原文件。拖动调整尺寸会更新笔记中的嵌入参数。

## 安装

目前通过安装包手动安装。

1. 下载并解压插件安装包。
2. 打开 Obsidian 仓库目录，找到 `.obsidian/plugins/`；没有该目录时可自行创建。
3. 将解压后的 `office-inline-preview` 文件夹放入其中。
4. 重启 Obsidian，在 **设置 → 社区插件** 中启用 **Office Inline Preview**。

安装后的目录结构应为：

```text
你的仓库/
└── .obsidian/
    └── plugins/
        └── office-inline-preview/
            ├── main.js
            ├── manifest.json
            ├── styles.css
            ├── README.md
            └── LICENSES/
```

### 更新

在 Obsidian 中关闭插件，将新版安装包中的文件覆盖到原插件目录，再重新启用插件。保留原有 `data.json`，无需删除设置。

## 快速使用

先将 Office 文件放入当前 Obsidian 仓库，例如：

```text
你的仓库/
├── 项目笔记.md
└── assets/
    └── documents/
        ├── 项目报告.docx
        ├── 数据统计.xlsx
        └── 工作汇报.pptx
```

在笔记中添加以下内容，每个嵌入链接单独占一行：

```markdown
![[assets/documents/项目报告.docx]]

![[assets/documents/数据统计.xlsx]]

![[assets/documents/工作汇报.pptx]]
```

切换到 **阅读模式** 或 **实时预览模式** 即可查看。路径按 Obsidian 的链接规则解析，可使用仓库路径或相对于当前笔记的路径。

## 操作方式

### 顶部工具栏

| 按钮 | 用途 |
| --- | --- |
| `i` | 查看 Excel 当前工作表的预览范围，或 PowerPoint 页数和预览说明；位于“打开文件”左侧 |
| 打开文件 | 通过 Obsidian 打开附件，复用当前标签页；具体打开方式可能由其他附件插件接管 |
| 刷新 | 重新读取附件并生成预览 |
| `</>` | 查看并定位当前预览对应的 Markdown 源码 |

文件名在标题栏中保持单行，过长时显示省略号；鼠标悬停可查看完整名称。

`</>` 查看的是笔记里的嵌入链接或代码块。实时预览中点击会定位并选中对应链接；阅读模式中点击会切换原始笔记到编辑视图并定位源码。

### Word

文字、表格和图片随页面一起按宽度缩放。调整笔记窗格或预览框宽度后，会自动重新适配。

文档的原始页边距保留；页面内容超过预览高度时，可纵向滚动。超出页面边界的宽表格也会纳入缩放范围。Word 页面最多显示到原始大小。

### Excel

工作表选择按钮位于预览区域底部，点击即可切换。只显示可见工作表。

默认显示每张工作表前 **500 行 × 50 列**，可在插件设置中调整。预览不会额外添加顶部列字母和左侧行序号，工作表自身的标题和编号仍会显示。

点击工具栏中的 `i`，可查看当前工作表的显示行列数、上限及预览说明。

### PowerPoint

幻灯片按演示文稿页序显示，并按预览框宽度等比例缩放。

- 点击底部 `‹`、`›` 按钮，查看上一页或下一页。
- 在页码输入框中输入页码，按回车或离开输入框后跳转。
- 幻灯片超过预览区域高度时，可纵向滚动。

当前支持静态预览，不播放动画、切换效果和音视频。

## 设置预览尺寸

### 拖动调整

拖动预览框右下角的角标，可同时调整宽度和高度。宽度不会超过笔记可用区域，拖动时的内容区高度范围为 **120–3000px**。

松开后，尺寸会写入当前笔记，例如：

```markdown
![[assets/documents/项目报告.docx#width=80%&height=450]]
```

同一路径的多个预览可以分别设置尺寸。拖动只更新当前嵌入，保留工作表、别名和其他参数；实时预览中的修改支持编辑器撤销。`office-preview` 代码块也会更新对应路径参数。

### 手动填写参数

在文件路径后添加 `#`，多个参数用 `&` 分隔：

```markdown
![[assets/documents/项目报告.docx#width=80%&height=450]]

![[assets/documents/数据统计.xlsx#width=100%&height=500&sheet=销售]]

![[assets/documents/工作汇报.pptx#width=90%&height=420]]
```

| 参数 | 作用 | 示例 |
| --- | --- | --- |
| `width` | 预览框宽度，支持百分比和像素；纯数字按像素处理 | `80%`、`600px`、`600` |
| `height` | 预览内容区高度，支持像素和 `vh`；纯数字按像素处理 | `450`、`450px`、`50vh` |
| `sheet` | Excel 初始显示的工作表名称；未指定或未找到时显示第一张可见工作表 | `销售` |

`height` 不支持百分比。像素尺寸参数最大为 3000px，百分比和 `vh` 最大为 100；实际宽度仍受笔记可用区域限制。

默认预览区域高度为 360px，标题栏另占少量空间；Excel 工作表按钮和 PowerPoint 翻页控件位于该预览区域内。

### 尺寸保存位置

每个预览的尺寸保存在笔记的嵌入链接或代码块中。

## 插件设置

在 **设置 → Office Inline Preview** 中调整：

| 设置 | 默认值 | 范围或格式 |
| --- | --- | --- |
| 默认宽度 | `100%` | 百分比或像素，例如 `80%`、`600px` |
| 默认高度 | `360px` | 像素或 `vh`，例如 `450px`、`50vh` |
| 文件大小上限 | 20 MB | 1–50 MB |
| 每张工作表最大显示行数 | 500 | 10–1000 |
| 最大显示列数 | 50 | 5–100 |

修改设置后，点击预览工具栏中的“刷新”。链接中明确指定的宽高优先于默认设置。

## 支持范围与限制

| 格式 | 支持内容 | 主要限制 |
| --- | --- | --- |
| `.docx` | 正文、基础段落格式、表格、内嵌图片 | 复杂分页、浮动对象、特殊字体和修订显示可能与 Word 不同 |
| `.xlsx` | 文本、数字、日期、基础粗体/斜体/对齐、已保存的公式结果 | 不重新计算公式，不显示图表和图片，数字格式不能完整还原 |
| `.pptx` | 文字、内嵌图片、形状、表格及部分图表 | 不播放动画和音视频；特殊字体、SmartArt、EMF/WMF、复杂图表等可能不能完整还原 |

Excel 日期以 ISO 日期显示。货币、百分比等可能显示为基础值；合并单元格仅显示主单元格内容，暂不合并预览网格。

不支持旧版 `.doc`、`.xls`、`.ppt`，也不支持加密文档、宏格式文件及移动端。旧版文件请先通过 Office 或 WPS 另存为 `.docx`、`.xlsx`、`.pptx`。

实时预览中的普通 `![[...]]` 嵌入需要单独占一行，暂不支持与文字混写，也不支持放在列表、引用或 callout 内。

插件会限制压缩文档的解压规模，避免过大的文档占用过多资源。通用上限为 100 MB 解压数据和 10000 个条目，PPTX 渲染库另有限制。增大文件大小设置不会取消这些限制。

## 常见问题

### 文件存在，但左侧文件列表里看不到

打开 **设置 → 文件与链接 → 检测所有文件扩展名**；部分版本中该选项叫“显示所有文件类型”。开启后仍未显示时，可重启 Obsidian。

正文预览与左侧文件列表显示是两个独立功能。插件可以解析 Office 嵌入内容，但没有向 Obsidian 注册这些格式的独立文件视图。

### 笔记中只显示链接或默认附件条

检查以下项目：

1. 插件已启用，文件扩展名为 `.docx`、`.xlsx` 或 `.pptx`。
2. 笔记处于阅读模式或实时预览模式。
3. 嵌入使用 `![[...]]`，且单独占一行。
4. 文件位于当前仓库中，路径正确，并已同步到本地。

若仍受主题或其他附件插件影响，改用 `office-preview` 代码块。

### 光标移到链接所在行后，为什么出现源码

这是实时预览的编辑行为。光标位于链接行时，链接保持可编辑，预览仍显示在下方；将光标移到其他行后只显示预览。源码模式则保留原始 Markdown 文本。

### 预览和 Office 中的显示效果不同

插件使用浏览器渲染文档，复杂布局和字体可能存在差异。需要核对完整排版、编辑文件或播放演示时，请使用 Office 或 WPS。

### 修改附件后内容没有更新

先保存附件，再点击工具栏中的“刷新”。同步盘中的文件还需要先完成本地同步。

### 文档会上传到服务器吗

插件在本机读取和解析文档，不将文档发送到服务器，也不依赖在线转换服务。Word 和 PowerPoint 使用限制脚本及外部资源的隔离预览容器；Excel 不执行公式或宏。仓库使用的同步服务仍按其自身设置运行。

## 第三方依赖

主要渲染依赖：

| 依赖 | 用途 | 许可证 |
| --- | --- | --- |
| docx-preview | Word 渲染 | Apache-2.0 |
| ExcelJS | Excel 读取 | MIT |
| JSZip | Office 压缩包读取 | MIT |
| @aiden0z/pptx-renderer | PowerPoint 渲染 | Apache-2.0 |

PowerPoint 渲染依赖还包含 ECharts、zrender 和 mtx-decompressor 等组件，其中 mtx-decompressor 使用 MPL-2.0。第三方许可证、声明及对应源码链接见 [LICENSES](LICENSES/) 目录。
